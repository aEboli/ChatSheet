# model-metadata-version-display Specification

## Purpose
确保模型倍率在设置页与对话选择器一致显示，并让标题栏使用准确的阿拉伯数字版本，按约定递增更新版本。目录刷新或连接切换时同步更新倍率，选择与保存始终使用模型 ID，避免旧倍率残留或显示名称被误作请求模型。

## Requirements

### Requirement: 模型倍率一致显示

系统 SHALL 在设置页和对话页展示 ACP 目录提供的有效非负数倍率，并 SHALL 使用模型 ID 进行选择和保存。

#### Scenario: 获取或刷新模型

- **WHEN** 模型目录包含有效倍率
- **THEN** 两处选择器显示对应倍率
- **AND THEN** 刷新相同模型 ID 的新倍率时更新显示

#### Scenario: 倍率无效或连接变化

- **WHEN** 倍率缺失、无效或目录失效
- **THEN** 不显示伪造倍率或旧连接的倍率

#### Scenario: 国际版倍率包含 credits 单位

- **WHEN** ACP 返回 `_meta.credits` 为 `x0.34 credits` 或 `x0.34`
- **THEN** 设置页和对话页均显示 `0.34x`，选择与保存仍使用模型 ID
- **AND THEN** `x0.00` 显示 `0.00x`，空值（例如 Auto）不补倍率，负数和未知文本不显示

### Requirement: 标题栏数字版本

系统 SHALL 在标题栏显示三段或四段阿拉伯数字版本号，保留楷体，不加“版本”前缀。
宿主程序集版本 SHALL 优先于静态回退值；四段版本的第四段表示可重复部署构建号。

#### Scenario: 加载三段功能版本

- **WHEN** 宿主返回版本 `0.10.3`
- **THEN** 标题栏显示 `0.10.3`

#### Scenario: 加载四段构建版本

- **WHEN** 宿主返回版本 `0.10.3.4`
- **THEN** 标题栏显示 `0.10.3.4`

### Requirement: 更新递增规则

系统 SHALL 对同一功能版本的重新部署递增第四段 `+0.0.0.1`；普通更新递增补丁版本，
大版本更新递增次版本，超大版本更新递增主版本。

#### Scenario: 同一功能版本重新部署

- **WHEN** 从已安装的 `0.10.3.4` 重新部署修复
- **THEN** 源码、程序集和静态页面版本统一为 `0.10.3.5`
