# ribbon-shortcuts Specification

## Purpose

为 ChatSheet 在宿主功能区中提供可逐步扩展的常用操作快捷区，让用户无需先在右侧面板中寻找入口，也能直接触发已有的确定性表格动作。快捷动作静默生效：不打开面板、不弹对话框。结果反馈落在面板已有的操作卡片上；功能区末尾另有一个撤销按钮，只撤销快捷区点出来的操作。

## Requirements

### Requirement: Settings, diagnostics, fit and undo have ribbon icons

The ChatSheet ribbon tab SHALL give “设置”, “诊断”, “适配当前表” and “撤销” each a distinct custom icon, in the same line-art style as the existing panel toggle. The icons SHALL be served by independent `getImage` callbacks so a missing resource or a mistyped callback name cannot silently blank every button at once.

#### Scenario: User opens the ChatSheet ribbon tab

- **WHEN** the host renders the ChatSheet ribbon tab
- **THEN** “设置”, “诊断”, “适配当前表” and “撤销” each show an icon as well as their label
- **AND THEN** the four icons are visually distinct from each other and from the panel toggle

### Requirement: Every shortcut has a hover description

“设置”, “诊断”, “适配当前表” and “撤销” SHALL each expose a screentip and a supertip. The undo button's supertip SHALL be generated by a callback so it can name the operation that will be undone.

#### Scenario: User hovers a shortcut

- **WHEN** the user hovers “设置”, “诊断”, “适配当前表” or “撤销”
- **THEN** Excel shows that button's screentip and supertip
- **AND THEN** the undo supertip describes the next ribbon operation that would be undone, or explains that none is available

### Requirement: Fit current sheet is available after settings and diagnostics

The ChatSheet ribbon tab SHALL expose a shortcut labelled “适配当前表” in the same group as the existing panel, settings and diagnostics controls. The shortcut SHALL appear after “设置” and “诊断”, establishing that trailing area as the ribbon's shortcut region. A separator SHALL sit between “诊断” and “适配当前表” so the shortcut region is visually distinct from the buttons that open a page. The existing fit control inside the panel SHALL remain available.

#### Scenario: User opens the ChatSheet ribbon tab

- **WHEN** the host renders the ChatSheet ribbon tab
- **THEN** it shows “设置”, followed by “诊断”, followed by a separator, followed by “适配当前表”, followed by “撤销”
- **AND THEN** the panel's existing fit control is still available

### Requirement: The ribbon shortcut runs the existing fit workflow silently

Activating “适配当前表” from the ribbon SHALL trigger the same fit action as the panel's fit control, without showing the ChatSheet panel, without navigating it, and without displaying a dialog. The action SHALL retain the panel's current horizontal alignment choice, defaulting to centre when no choice has been made. Its progress, result, failure and undo availability SHALL use the existing manual-operation card workflow rather than a separate execution or notification path; the card becomes visible when the user next opens the panel, tagged as originating from the ribbon.

#### Scenario: User activates the shortcut while the panel is already open

- **WHEN** the user activates “适配当前表” and the panel is already visible
- **THEN** the panel stays on whatever page it was showing
- **AND THEN** one fit action starts with the panel's current alignment choice
- **AND THEN** the transcript records its existing manual-operation card, marked as a ribbon action

#### Scenario: User activates the shortcut while the panel is closed

- **WHEN** the user activates “适配当前表” and the panel is not visible
- **THEN** the panel remains hidden
- **AND THEN** one fit action starts with the panel's current alignment choice
- **AND THEN** no dialog is shown
- **AND THEN** opening the panel afterwards shows the same manual-operation card the in-panel fit control would have produced, marked as a ribbon action

#### Scenario: Fit cannot be performed

- **WHEN** the shortcut-triggered fit fails
- **THEN** the failure is shown on the same manual-operation card used by the panel fit control
- **AND THEN** no separate ribbon-only result path is introduced
- **AND THEN** no dialog is shown

### Requirement: A cold-start shortcut activation is not lost

If the panel or its embedded page is still loading when the ribbon shortcut is activated, ChatSheet SHALL retain the activation until the page has completed loading and then dispatch one fit action. It SHALL NOT silently discard the activation, execute it more than once, or keep it indefinitely after the page fails to load.

#### Scenario: User activates the shortcut before the panel page loads

- **WHEN** the user activates “适配当前表” before the panel page has completed loading
- **THEN** ChatSheet creates the panel in the background if needed and keeps it hidden
- **AND THEN** exactly one fit action starts after the page is ready

#### Scenario: The panel page never becomes ready

- **WHEN** the user activates “适配当前表” and the panel page does not become ready within a bounded wait
- **THEN** ChatSheet discards the pending activation
- **AND THEN** it records the reason in the add-in log
- **AND THEN** it does not run the fit later when some other navigation succeeds

### Requirement: Ribbon undo only undoes ribbon shortcuts

The ChatSheet ribbon tab SHALL expose a “撤销” control after “适配当前表”. Activating it SHALL undo the most recent ribbon-originated operation that has not already been undone. It SHALL NOT undo operations started from the panel or by the model. It SHALL reuse the panel card's existing undo button rather than a second restore implementation. The control SHALL be disabled when no ribbon-originated undo is available.

#### Scenario: User undoes after a ribbon fit

- **WHEN** the user has activated “适配当前表” from the ribbon and then activates “撤销”
- **THEN** the most recent ribbon-originated fit is undone
- **AND THEN** a fit started from the panel, if any, is left untouched

#### Scenario: Nothing to undo

- **WHEN** no ribbon-originated operation is available to undo
- **THEN** the “撤销” control is disabled
- **AND THEN** activating it does not change the workbook

#### Scenario: The undo would overwrite a later change

- **WHEN** undoing the ribbon operation would cover a later change that has not itself been undone
- **THEN** the first activation does not restore
- **AND THEN** the control's label becomes “仍然撤销”
- **AND THEN** a second activation performs the undo
