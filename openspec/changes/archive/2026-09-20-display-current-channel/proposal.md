# 顶部显示当前渠道

## Why

对话面板顶部缺少当前接入渠道，用户无法直接确认正在使用的连接。

## What Changes

- 在版本号之后、导航图标之前的空白区域显示已保存的实际渠道。
- 本机 Codex 显示 `codex cli · 服务商名称`，例如 `codex cli · Moon Stars`；名称动态取自当前选中服务商，缺失时使用服务商标识，再不可得时仅显示 CLI 名称。自动选择模式使用实际解析到的 CLI。
- 自定义 API 固定显示 `DIY`。
- WorkBuddy 显示官方返回的当前用户名；无法取得用户名时显示 `WorkBuddy`，不将账号 ID 当作用户名。
- 保存切换渠道、账号状态更新后刷新；未保存的设置草稿不改变标题栏。窄面板省略文本，悬停和读屏提供完整内容。

## Impact

修改标题栏、样式、设置桥的展示字段和必要的提供器名称读取；验证渠道映射、切换刷新与窄面板布局。不改变连接、认证或对话行为。

## 与已有提案的关系

`workbuddy-session-safety` 尚有标题栏显示渠道和身份的规划。本次按用户最新要求明确展示用户名，已同步其重叠规范，避免双重渲染；会话保护不属于本次范围。

## 确认状态

用户已确认并完成实现。
