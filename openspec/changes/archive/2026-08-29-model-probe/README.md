# model-probe

一期让用过的模型自动带上「能用 / 报错说没这个模型」的标注。但从没发过一轮的模型
只能显示「未确认」——这一期补上「对着它点一次就知道」。

- **一条最小请求**：不带工具、不带图片、不传思考参数、输出上限压到最小。
- **必须是真实请求的子集**：否则探测通过而真实对话失败，绿灯反而骗人。这是本期
  大半工作量的来处——四个前提缺陷得先修（见 `design.md`）。
- **走既有的流式通路**：不新写非流式读取。三个协议的解析器已经能认体内错误，
  新写一条只看状态码的路等于把它们扔掉。
- **一次只飞一个**：探测之间排队，对话在飞时不许探测。限流判未知，等于花了钱没
  拿到答案，还可能把用户那一轮真正带着上下文的请求给限掉。
- **名单可以一次点完**：串行、带进度、可中断、已得结果保留。只对名单提供批量，
  不对完整目录——上百个 ID 就是上百次付费请求。

判定的口径、三态的含义、「标注永不隐藏」都沿用一期，本期不改。
