# 设置页网络代理连接

## Why

自定义接口和本机 CLI 的请求目前只能直连。部分用户需要通过系统代理、HTTP 代理或 SOCKS5 代理访问接口，且代理密码不应写入明文设置文件。

## What Changes

- 在面板顶部新增独立“代理”入口，位于“设置”与主题切换之间；代理页支持直连、系统代理、HTTP、HTTPS 和 SOCKS5。
- 代理区支持保存多套带名称的配置，用户可手动切换当前配置，并可开启失败自动切换到下一套配置。
- 代理配置从通用设置页移出，在独立代理页中编辑、测试和保存；代理地址与端口在同一行展示。
- 宿主侧将代理类型、地址、端口、用户名写入设置；代理密码复用 DPAPI 密钥存储。
- 模型目录、对话流、模型探测和视觉中转共用解析后的代理配置。
- 提供代理连通性测试，测试结果只返回状态与耗时，不返回凭据。
- 代理配置进入模型目录连接键，代理变更不会复用另一代理下的目录。

## Non-goals

- WorkBuddy ACP 本身的进程网络不由 ChatSheet HTTP 客户端接管。
- 不实现 Shadowsocks、VMess 等需要独立协议栈的代理协议。
- 自动切换只针对尚未交付响应内容的网络/网关瞬时故障，不对已开始输出的流式响应重复发送。

## Capabilities

### New Capabilities

- `network-proxy-connection`：独立代理页面、代理配置管理、安全保存与请求一致性。
