## Context

已安装版本为 0.10.1。WorkBuddy 快捷方式指向本机标准安装目录，CLI 支持 ACP JSON-RPC。现有 HTTP 客户端不能发送没有 URL 和 token 的授权连接。

## Decisions

- 使用现有流事件接口抽取 `IChatStreamClient`，HTTP 与 ACP 分别实现，按连接类型选择。ACP 初始化、建会话、选择模型后发送 prompt。
- WorkBuddy 自带工具关闭，ChatSheet 工具走已有文本协议。首次 prompt 携带系统指令及历史，后续仅传新工具结果或用户消息，避免重复历史；系统指令更新时补传。
- ACP 标准输出仅作协议解析，stderr 仅消费。启动失败、未登录、超时输出固定中文提示；服务端权限请求返回取消，不授予额外工具权限。
- 对话和探测均支持取消并回收自建进程；探测使用适合 CLI 启动的截止时间。
- 模型 ID 仍是选择和保存值。倍率独立缓存并作为名称旁的元素显示，不改变模型 ID 的 DOM 文本或现有测试定位。

## Validation

先补 ACP 进程夹具覆盖中文流、会话续传、权限请求和取消；通过独立实机测试确认 hy3 回复、工具结果续传及模型探测。运行现有 .NET、前端测试与构建，检查窄面板布局。安装后核对程序集、网页版本和 COM 注册诊断。
