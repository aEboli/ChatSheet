# approval-as-review

默认审批今天只告诉用户「改哪、改多少格」，不告诉「改成什么」。
点「允许」是一次跳跃，不是一次核对。这是 WebView2 当初要做 diff 预览的那件事，还没做。

本期四件必须一起落地的事，拆开会让另外几件继续骗人：

- **审批卡看见内容**：写值/写公式给出原值 → 新值的截断对照；格式卡写明当前是否混合。
- **地址可点**：审批卡、操作卡、轮次摘要上的范围跳到 Excel 里对应格子。
- **撤销诚实**：建图必须带上 Excel 赋的名字，否则不给按钮；混合格式不承诺还原；重叠时先警告。
- **「每轮确认」不再等于逐项审批**：第一次允许之后，本表、本风险类自动放行；结构操作除外。

`read_profile`、插入/删除行列、边框不在本期。那些是下一刀，审批还看不见内容时加动词只会让人更快地点「全部允许」。
