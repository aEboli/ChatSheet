# 设计

## 统一入口

设置页使用一个模型获取流程处理自动与手动刷新。渲染本身不触发网络请求，避免组件状态变化导致 CLI 重复探测。初次进入、模式切换和 CLI 来源变化显式启动获取。自定义接口资料未填写完整时显示待配置，保留手填模型。

## 状态与缓存

连接键沿用模型目录的模式、CLI 来源或自定义协议与地址。面板只在内存中记住已选模型、目录、授权摘要和组件状态；自定义密钥草稿单独保留在表单内存，不进入缓存键、日志或持久化。切回时恢复该连接状态并获取更新，不复用另一模式的模型。

在途请求按连接合并。模式修订号与连接/密钥修订号共同限制响应投递，错误分支和重试推送也必须遵守。暂时失败保留当前连接已有目录并标记待确认；官方明确未授权时清除相应目录和模型。后端仅短时缓存成功授权，避免未授权或暂时失败被当作有效缓存。

WorkBuddy 登录由官方客户端或 CLI 保留。切换只读取 ACP；不通过自动 authenticate 来“恢复”状态。进程重新启动时重新读取官方授权，不将旧界面缓存当作实际授权证明。

## 布局

授权区左侧为产品名称和连接状态，右侧为登录/账号及组件操作。签到作为内容宽度的辅助状态，国际版不适用提示不再铺满整行。窄栏允许信息分行，按钮维持自然宽度和可点击高度。

## 验证

通过真实消息桥模块的 DOM 回归验证四种模式、快速 A→B→A、CLI 来源变化、异常恢复、密钥草稿和保存边界；通过真实 WebView2 检查宽窄布局并截图。实机只读取国内/国际已有授权，不为测试退出或切换账号。
