# 统一四种接入模式的自动获取与快速切换

## Why

用户反馈每次切换 WorkBuddy 国内版、国际版仍需要手动点击“自动获取”，要求四种模式统一优化，并压缩授权区留白、保留登录状态以便快速切换。实机两种 WorkBuddy 均可直接通过已有官方登录读取模型，当前问题主要在面板状态被清空、获取入口分散及缺少一致的加载与恢复行为。

## What Changes

- 进入设置页、切换四种接入模式或 CLI 来源时，自动检查当前连接并获取模型；手动按钮统一作为刷新入口。
- 按连接保留本面板最近的目录与模型选择，切回后立即恢复并自动核验。WorkBuddy 复用官方登录，不因模式切换触发 authenticate。
- 获取、空目录、未登录、暂时失败分开显示；暂时失败保留同一连接的上次目录，明确未授权则清空。
- 合并同一连接的在途请求；成功、错误和重试通知均校验请求归属，旧模式不能覆盖当前页面。
- 授权信息和按钮并排，签到与组件信息紧凑展示，兼容 360px 窄栏和截图所示宽面板。

## Capabilities

### New Capabilities

- `connection-mode-refresh`：四种模式统一自动获取、状态恢复与请求归属。

### Modified Capabilities

- `workbuddy-settings-panel`：授权状态和按钮的紧凑布局。
- `workbuddy-authorization`：切换复用已有登录与短时状态缓存，暂时失败不清除当前模型。

## Impact

修改设置页、共享模型目录、消息桥及定向测试。保留显式“保存设置”流程，模式预览不自动保存。不读取或复制 WorkBuddy 凭据，不新增账号存储或后台常驻任务。已有 `workbuddy-session-safety` 中的标题栏账号展示与额外来源管理不属于本次任务。
