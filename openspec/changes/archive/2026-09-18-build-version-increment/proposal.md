# 提案：增加可重复部署构建号

## Why

当前加载项的程序集已经能够使用四段版本号，但标题栏只显示前三段。
同一功能版本重新部署修复后，用户无法从面板确认已经加载了最新构建。

## What Changes

- 当前构建从 `0.10.3.0` 更新为 `0.10.3.1`。
- 标题栏和静态回退值显示完整的三段或四段数字版本。
- 规定同一功能版本的重新部署递增第四段 `+0.0.0.1`；普通补丁、次版本和主版本规则保持不变。
- 发布脚本接受可选的第四段版本号。

## Non-Goals

- 不创建 GitHub Release 或上传发行包。
- 不改变 WorkBuddy、ACP 或模型目录行为。

## Capabilities

### Modified Capabilities

- `model-metadata-version-display`: 支持显示可重复部署构建号。

## Impact

修改项目版本元数据、前端版本格式化、版本测试、发布脚本和版本规则文档；
重新构建并安装本地加载项。
