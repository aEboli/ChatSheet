# picker-legibility

前两期把「哪几个模型真能用」这件事做出来了，但把结论画得太小：判定只落在模型名之前
一个 7px 的点上，而紧挨着它的模型名无论可用不可用都是同一个黑。一列几十行扫下去，
「能用」与「报错说没这个模型」看起来完全一样。

- **判定落在模型名的颜色上**：不可用的名字变红。点保留，作为第二处标记。
- **可用刻意不上绿**：绿是当前选中项的颜色，两处都用绿会分不清「这个能用」与
  「现在用的是这个」。需要一眼看见的是哪几个**不能用**。
- **浮层竖着分两段**：模型在上、档位在下，两段各占整个浮层的宽度。面板常见宽度
  320-420px，左右分栏时模型段装不下一个长模型 ID，档位段装不下「Minimal」加一个标注。
- **档位一行一档**，用途说明收进悬停；「会降级」仍留在行上——它不是解释，
  是「选了不生效」。
- **「试一下」平时藏着**，悬停这一行或键盘聚焦到行内时浮出来。未确认的模型往往是
  列表里的大多数，每行常驻一个按钮会把这一列变成按钮墙。

判定的口径、三态的含义、名单与开关的行为、「标注永不隐藏」都不动。
