# 设计：WorkBuddy 模型显示与版本标识

## 模型目录

`WorkBuddyProvider` 只从 `_meta.credits` 接受 `x`/`X` 加非负有限十进制数字，统一格式化为
两位小数的 `0.00x` 字符串。其他值被丢弃。`AgentChannels` 在授权状态和模型列表 payload
中增加 `multiplier`；不把原始 `_meta` 对象传到 WebView。

设置页先按 `modelId` 去重，再统计显示名称重复次数。选项文字按“名称 倍率 · ID”组成，只有
名称重复时才追加 ID；选项的 `value` 始终为原始 `modelId`。普通字符串模型目录继续只显示
模型 ID。共享模型目录缓存仍只存稳定 ID，不扩大缓存的元数据范围。

## 状态与布局

模式切换清空模型、有效模型、选择确认、旧就绪状态和授权状态。WorkBuddy 模式的顶部状态条
不再读取旧模式的 `readyDetail`，只显示 WorkBuddy 状态并明确普通对话尚未接入。模型行的按钮
固定为不换行的非伸缩项，模型输入框承担剩余宽度。

## 版本显示

项目版本统一更新为 `0.10.1`。标题节点带 `data-version` 回退值，页面先显示回退值，宿主
`host.info.addInVersion` 返回程序集版本后替换。只转换前三段，用 `零壹贰叁肆伍陆柒捌玖`
逐位映射并以“点”分隔，因此 `0.10.1` 显示为“版本 零点壹零点壹”；CSS 指定 `KaiTi`、
`STKaiti` 和 serif 回退。

版本规则写入 README：普通更新 `+0.0.1`，大版本更新 `+0.1`，超大版本更新 `+1`。
