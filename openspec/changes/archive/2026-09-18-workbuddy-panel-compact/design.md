# 设计

授权区采用三层信息：

1. 状态芯片只显示“已授权 / 未授权 / 授权组件不可用”。
2. 运行时芯片只显示 ACP 登录入口是否可用；按钮根据 `canLogin` 决定是否可点，不能把 `standalone` 当成登录能力。
3. 安装、登录、签到操作保留短按钮或短状态；完整原因放在 `title`、`aria-label` 或主动展开的 `details` 中。

WorkBuddy 模式不渲染通用 ready banner，避免同一授权状态出现两次。国内与国际版继续共享布局但按连接模式隔离模型和签到行为。静态字段提示使用原生 `details`，动态错误和进度仍写入状态行。
