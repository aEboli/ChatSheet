## Context

当前 `fit_range` 先设置对齐，再对整列和整行调用 `AutoFit`。长文本会使列宽超过可读范围；如果先换行再自动调列宽，宿主的列宽计算会受换行状态影响，结果不稳定。

## Decisions

- 保持现有对齐和撤销流程，不新增工具或 UI 入口。
- 执行顺序固定为：对齐 → 自动调列宽 → 将超过 100 的列宽限制为 100 → 设置 `WrapText` → 自动调行高。
- 只对本次 `fit_range` 的目标列应用上限；独立的 `autofit_range` 工具保持原行为。
- 将 `WrapText` 作为适配对齐快照的一部分，统一值走范围级保存，混合值在允许逐格快照时保存矩阵；无法完整采集时继续按现有规则不提供撤销。

## Risks / Trade-offs

- 部分宿主可能拒绝读取或设置列宽；沿用现有 COM 错误传播，不报告虚假成功。
- 把宽列压到 100 可能增加行高，这是预期结果；重新自动调行高保证换行内容可见。
