# 修复国际桌面端模型上下文

## Why

国际桌面端 CLI 未继承桌面宿主标识和产品快照时，ACP 实测只返回 4 个基础模型，与桌面端的完整目录不一致。

## What Changes

- 国际模式优先使用 WorkBuddyAI 桌面端。
- 直接启动和 WPS 代理启动均向官方 CLI 传入桌面宿主标识及该产品目录最新会话快照路径。
- 模型查询和对话复用相同启动逻辑，名单及倍率仍完全来自 ACP，不在界面补造模型。
- 快照不存在或目录不可读时保留原有 ACP 启动方式。

## Impact

涉及提供器路径选择、进程启动环境和针对性回归测试；不读取凭据，不修改官方配置。

## 确认范围

用户已明确要求消除渠道导致的模型目录差异并更新安装。本修复落实该范围。
