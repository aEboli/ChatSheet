# v0.10.3.15 Office-helper 文档支持与代理页面

- Excel/WPS 表格与 Microsoft Word/WPS Writer 入口统一显示为 Office-helper；保留既有 ChatSheet Excel ProgID、CLSID 和设置目录，兼容已有安装。
- 新增独立 Word 加载项，支持读取文档结构与明确目标，并对文本、段落、表格等提供文档工具。修改后回读结果；只有能建立可靠快照时才提供撤销。
- 安装器同时注册表格和文档加载项，处理 Word/WPS Writer 的宿主登记、WPS 白名单与禁用项；Windows ZIP 包含 Word 加载项程序集。
- 新增独立“代理”页面，位于应用栏“设置”之后、主题切换之前。支持直连、系统代理、HTTP、HTTPS、SOCKS5、多套配置、连接测试和失败后切换。
- 代理用户名和密码按配置保存；密码通过 Windows DPAPI 保护。模型目录、测试请求和后续对话使用当前代理配置。
- Word 面板复用现有模型与 WorkBuddy 接入，并保留 Word 文档目标、审批和工具边界。

## 验证与边界

Release 构建通过（0 警告、0 错误）；网页回归 37/37、Word 工具测试 49/49、WorkBuddy 测试与可靠性回归通过。Windows ZIP 的 SHA-256 与 sidecar 一致，包内包含 Word 加载项和 Web 面板入口。

本次发布没有执行新的 Microsoft Word/WPS Writer 桌面宿主加载冒烟。两种宿主的可用成员仍取决于安装版本；未能可靠验证或撤销的操作会返回具体状态，不承诺所有宿主功能完全一致。
