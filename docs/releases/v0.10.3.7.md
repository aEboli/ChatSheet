# ChatSheet v0.10.3.7

此版本修复国际版 WorkBuddy 的本机登录态读取、授权复用和模型倍率显示。

- 正确识别 WorkBuddyAI 国际版，优先读取桌面端 `.workbuddy-ai` 的已有授权，保留独立 CLI 后备。
- 普通登录优先复用官方组件保存的授权；只有“切换账号”会主动重新授权。
- 切换回授权接入模式时自动恢复当前状态与模型目录。
- 兼容 `x0.34 credits` 等官方倍率格式，设置页和对话页一致显示；零倍率保留，缺失倍率不补造。

构建、针对性回归和真实 WebView2 面板验证通过；实机验证新进程可继续使用已有国际版授权。

安装前请保存并完全退出 Excel/WPS，运行包内 `install.bat`；重新打开表格软件后确认标题栏为 `0.10.3.7`。本包为本机构建，未发布至 GitHub Release。
