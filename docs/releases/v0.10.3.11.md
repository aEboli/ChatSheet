# ChatSheet v0.10.3.11

修复 WorkBuddy 切换账号连带退出桌面客户端、登录后面板不刷新及重复打开浏览器的问题。

- 切换账号交给当前授权来源的官方客户端；只有明确未授权且登录进程再次确认无用户时才允许首次登录。
- 官方 CLI 负责首次打开授权页，面板不重复开窗；手动重开仅在当前操作存活时可用。
- 登录等待期间检查同一来源，确认授权后立即更新模型并恢复按钮；从客户端返回时自动刷新。
- 登录互斥覆盖多个面板和宿主；取消或失败保留已有状态，过期通知和链接不能影响新操作。

独立 CLI 没有对应桌面账号入口时，面板提示在当前来源的官方 CLI 中管理账号。验证使用模拟登录和真实账号只读查询，不替用户退出或重新授权。

保存并完全退出 Excel/WPS 后，运行安装脚本更新。本版本未发布 GitHub Release。
