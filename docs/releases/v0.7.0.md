# ChatSheet v0.7.0

`v0.7.0` 管的是同一件事的两半：**点了之后有没有反应。**

一半是面板压根没出来——`v0.6.0` 里点功能区的「ChatSheet 面板」而面板不出现有十一条
路径，全部对用户静默，加载项里一处提示都没有，而面板本身正是坏掉的那个东西。现在
会说清成因、给出一个能做的动作，并把其中三条成因就地修掉。

另一半是点了有反应但看不出来。禁用的按钮点下去什么都不发生，而「什么都不发生」既
可能是拒绝、也可能是没点中、或者程序卡住了；顶栏三个图标点了之后结果出现在别处，
图标自己不动一下就没有就地回执。现在这两处都有了反馈。

版本号走到 `0.7.0` 是因为两边都新增了此前不存在的能力（失败提示与动效反馈），
不只是把既有的东西画得更清楚。

## 一、面板没出来时说清原因

点了面板而它没出现时，现在弹一个原生对话框：一句话说清发生了什么、括号里补最常见
的触发条件、最后一句交代还能做什么，并附上日志路径。

| 提示说的成因 | 该做什么 |
| --- | --- |
| 文件在「受保护的视图」里打开 | 点表格上方黄色提示条里的「启用编辑」，再点面板 |
| 当前没有打开的工作簿 | 先新建或打开一个工作簿 |
| Excel 正忙 | 关掉表格上的对话框、等当前操作结束 |
| 没有开放建立面板所需的接口 | 完全退出 Excel 重开；仍不行就重跑 `install.bat` |
| 面板控件没能创建出来 | 重跑 `install.bat`，然后完全退出 Excel 再打开 |
| 显示被拒且重建无效 | 完全退出 Excel 重开；每次都这样就带日志反馈 |

文案里不出现「窗格」「CreateCTP」「COM」这类只对开发者有意义的词，有单测钉住。

### 只读工作簿不是成因

这一条值得单独说，因为它是这次报障的方向，而它是个误导。只读工作簿照常能开面板，
改文件属性没有意义。真正拦住面板的是**没有可停靠的文档窗口**。

两者容易混为一谈，是因为「受保护的视图」恰好同时是只读的——那种工作簿不属于
`Workbooks`、不贡献窗口，所以窗格没有能挂的地方。判定里刻意没有「只读」这个维度，
有一条单测专门钉住这一点。

### 顺带修掉的三条「点了没反应」

- **面板控件被宿主销毁后再也开不出来。** 原先只看「面板对象还在不在」就早退，而没
  有任何地方会在宿主销毁窗格后把它置空。真实发生过：某次之后每次点击都在戳一个已
  经拆掉的对象，整个 Excel 会话再也开不出面板。现在显示失败会就地重建并重试一次。
- **功能区按下态不再盲信。** 用面板自己的关闭按钮关掉面板时宿主不通知加载项，功能
  区仍记着「按下」，下一次点击于是去隐藏一个已经隐藏的面板。现在目标状态按面板的
  实际可见性取反。这是日常最容易撞上的一条，此前日志里连一句警告都没有。
- **挂在别的工作簿窗口上也算打不开。** Excel 2013 起每个工作簿各有框架窗口，
  在 A 工作簿开了面板、切到 B 再点按钮时，窗格报告自己可见（它在 A 里确实可见），
  而用户眼前什么都没有。这条路径不抛异常也不返回失败，靠错误捕获永远发现不了。
  现在比对窗格父窗口与当前活动窗口的句柄，确凿不一致才重建。

## 二、点击反馈与进场动效

| 位置 | 反馈 |
| --- | --- |
| 顶栏的对话、设置页签 | 按下时图标缩小，松开后一段短促回弹（0.26s） |
| 顶栏的主题切换 | 新图标（月亮↔太阳）旋转淡入（0.32s）——它点了换的是图标本身，缩放在换脸的瞬间读不出来 |
| 对话流的新内容 | 气泡、工具卡片、提示条淡入并上浮 5px 进场（0.18s） |
| 操作栏按钮 | 按下时整个按钮微缩到 0.92 |
| 气泡圆角 | 主圆角放大到 10px，贴边的那个下角收成 4px（用户右下、助手左下），窄栏里留白被压缩后角的指向仍读得出来 |

顶栏那三个为什么需要就地回执：它们点了之后结果都出现在别处（换页、换主题），
图标自己动一下是「点到了」唯一的当场证据。

### 点不动的按钮横向抖一下

点击已禁用的按钮会让它横向抖 0.19 秒。覆盖面板里全部禁用按钮：发送、撤销、批量
确认与测试、设置页的取模型与保存、审批卡片的三个按钮，以后新增的也自动覆盖。

参数是从用户提供的参考视频里逐像素量出来的（8.96s、1852×1080、60fps）。取其中两次
点击事件，结果一致：时长 184ms 与 183ms、峰值偏移 56.3px 与 59.7px、方向反转各 5 次
（6 个半程）、首程都向左、弦宽变化 <2%（纯平移不缩放）、竖向偏移在 ±0.5px 噪声内、
按钮颜色恒定不变。据此取 0.19s、6 个半程、首程向左、振幅包络 1.0/0.7/0.6/0.6/0.3/0.3。

幅度用定值 3px 而不是按比例：视频里 12.6% 是那个 461px 大按钮自己的比例，面板里最常
见的禁用按钮是 26px 图标按钮，3px 恰好 11.5%，相当；而设置页那种一百多像素宽的按钮
若也按 12.6% 就要甩出 15px。

顺带把「按下微缩」改成只对可点的按钮——禁用的按钮没有「按下」这件事，缩一下等于说
点成了。

### 减少动效

系统开启「减少动效」时全部动画一律不放，且不留下任何残留状态。这一条不只是 CSS 里
关掉动画：动画不起播时结束事件不会来，靠它清理的类会永久留在节点上；用户中途改
Windows 的「动画效果」开关时媒体查询实时翻转，那一帧所有残留的类会同时起播——整条
对话流凭空一起闪一下。所以加类之前就先问一次偏好，不加类就没有这条路。

## 升级须知

无需改配置，设置、密钥、常用名单与面板宽度都保持原样。覆盖安装前请完全退出 Excel。

### 两处只有真实输入才发现的缺陷

这一版有两个缺陷是造出来的事件永远测不到的，记在这里：

- **重新 append 一个已在场的节点会把运行中的动画取消并从头重播。** DOM 规范里移出
  文档即取消动画，而 `append` 一个已是子节点的元素就是「先摘再插」。所以「只在首次
  挂载时加动画类」挡不住重播——类还在。实测进度从 170ms 退回 0ms，表现是气泡可见地
  闪两下，代码里没有任何痕迹。
- **`animationcancel` 是异步派发的。** 连点时为了重放先摘类，那一下取消了运行中的
  动画；等取消事件到达时新动画已经在跑，清理处理器若无条件摘类就把它掐了——真实
  鼠标连点两下只抖一次，就是这个原因。

### 未验证

- **动效未做目视确认。** 开发环境读不了图片，回弹曲线是否顺眼、抖动与参考视频像不
  像，只有人眼能判断。所有参数都是从像素里量出来或算出来的，不是看出来的。
- **「用面板自己的关闭按钮关掉、再点一次功能区」没有在真实 Excel 里走通。** 那个关
  闭按钮不在可访问性树里，复现不出「宿主已隐藏而功能区仍记着按下」这个前提。该路径
  的逻辑成立且相邻行为已验证（连续开关四次、SDI 那一项的日志里能看到按下态被改判），
  但这个具体组合仍只是逻辑上成立。

### 已知但本版未修

**面板视口退化时宽度校准会把面板放大到半个屏幕并落盘。** Excel 窗口最小化时点开面
板，视口只有 69 CSS 像素，校准据此把宿主宽度拉到屏幕一半并写进设置，之后每次打开都
是这个宽度。这是既有逻辑的缺陷：校准没有对「视口小到不可能是真实布局」设下限。
它属于宽度那条线，本版只记录。
