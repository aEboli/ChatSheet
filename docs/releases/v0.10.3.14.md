# v0.10.3.14 表格工具开放

- 默认自动执行表格修改，仍可主动切换逐项或每轮审批。
- 工具步数默认 0，表示持续执行直到完成或停止；连续八次相同失败会停止无进展重试。
- 解除原有 5000 格操作拒绝。读取每页 5000 格，通过 next_offset 连续获取；写入自动分块并返回部分失败进度。撤销快照预算独立，不以没有快照阻断修改。
- 新增 excel_object，支持当前工作簿对象的属性读取、设置和方法调用。行列、筛选、边框、条件格式、验证规则、命名区域、图表、透视表、冻结及页面设置无需为每个成员单独注册工具。
- get_workbook_info 返回宿主版本、对象工具入口与操作类别；具体宿主成员是否支持以实际执行和读回为准。
- 多区域格式等宿主支持的操作可以通过对象入口执行；原有矩阵工具仍要求连续区域，避免首区域之外的数据被静默遗漏。

## 验证及边界

Excel 16 和本机 WPS 均使用独立临时工作簿验证。覆盖数据写入读回、筛选、边框、数据验证、条件格式、命名区域、行隐藏、单元格插入、冻结、页面方向、透视表创建和字段设置，以及分页边界与分块中断。

本机 Excel 的 Range.Copy 返回宿主错误，独立 COM 调用也复现；WPS 同场景复制成功。因此不能将本版本描述为所有 Excel/WPS 功能已经逐项验证。工具调用失败会显示具体宿主错误，不伪装成功。

通用对象操作不提供自动撤销；大范围操作能否撤销取决于快照预算。保留工作簿绑定、用户停止、参数合法性和宿主保护状态。通用入口不提供文件系统、应用程序全局、宏或网络访问。
