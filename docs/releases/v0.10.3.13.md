# ChatSheet v0.10.3.13

这是一次面向 WorkBuddy 国际版模型目录一致性的补丁发布。核心修复是让 ChatSheet 以官方桌面端的产品上下文启动 ACP，从同一个官方来源读取模型，而不是只看到 4 个基础档位。

## 用户可见改进

- WorkBuddy 国际版从桌面端启动 ACP 时继承 `CODEBUDDY_HOST=workbuddy-desktop`。
- 同时传入 WorkBuddyAI 当前产品快照，桌面端和 ChatSheet 现在共享完整的 `cli` 模型目录。
- `0.00x` 免费模型、完整倍率、模型名称和能力信息由官方 ACP 返回，ChatSheet 不硬编码模型名单。
- WPS 直接启动和 WMI 代理启动使用相同的产品上下文，避免两个渠道显示不同模型。
- 独立 CodeBuddy CLI 继续使用自己的 `.codebuddy` 配置，不会混入 WorkBuddyAI 桌面目录。
- README、安装指南和发行包链接统一更新到 v0.10.3.13。

## 验证结果

- Release 构建：0 个警告，0 个错误。
- WorkBuddy 账户/路径回归：全部通过。
- 国际版实机 ACP：返回 21 个模型，其中 20 个带倍率、3 个为 `0.00x`。
- ACP 会话实际接受全部 21 个模型的 `session/set_model`。
- OpenSpec 严格校验：通过。
- 安装包与 Release 构建产物使用相同 SHA-256。

## 安装

下载 `ChatSheet-v0.10.3.13-win.zip` 与 `.sha256` 文件，先核对 ZIP 哈希，再完整解压并运行根目录的 `install.bat`。升级前请保存并完全退出 Excel/WPS。
