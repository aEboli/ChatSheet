# ChatSheet v0.6.0

`v0.6.0` 把上一版留下的半个问题补完：**知道哪几个模型能用之后，怎么一眼看出来。**

`v0.5.0` 已经能对模型给出「能用 / 报错说没这个模型 / 未确认」的结论，但结论只画在模型名之前一个 7px 的圆点上——一列几十行扫过去，能用与不能用看着是一样的。本版把结论给到这一行里最大的那块字，并新增「测试」一键测完整份目录。版本号从 `0.5.0` 走到 `0.6.0`，是因为新增了一项此前不存在的能力（批量测试整目录），而不只是把既有标记画得更清楚。

## 问题

上一版把「哪几个模型真能用」这件事做出来了，但把结论画得太小。

判定只落在模型名之前一个 7px 的圆点上，而紧挨着它的模型名无论可用不可用都是同一个黑。一列几十行扫下去，用户看到的是一整列同样的黑字，要确认某一行的结论得逐行盯着那个点看——而那正是这个标记本来要省掉的工作。

行上确实还有一句 10px 的结论小字，但它让每一行都变成两行，把列表密度砍掉一半；结论没变明显，可读的行数反而少了一半。

另外还有两处：从没用过的模型只能一个一个点「试一下」，几十个 ID 就得点几十次；而模型 ID 一长就折成两三行，一列几十个模型翻成上百行，找一个反而更难。

## 新增：一键测试全部模型

列头新增「测试」，点一次把整份目录逐个测过来，**并发 5**。测出来能用的模型名变绿，报错说没这个模型的变红，被限流一类判「未确认」的不上色。

**代价写在按钮上。** 悬停说明会报出这一次会发多少条请求，以及并发可能撞上限流、而限流记为「未确认」不是「不可用」——花了钱没拿到答案。这不是可选的提示：目录有几十个 ID 就是几十次计费请求，而按钮只有两个字，点下去之前没有别的地方会告诉你这件事。

**边跑边上色。** 每测完一个就更新那一行，不等整批结束。几十个模型跑一遍要好一阵，只在结束时上色的话中途整列都是「未确认」，看起来像卡住。

原有的「确认」保留，作用范围仍是常用名单——两个动作的代价差一个数量级，混成一个按钮就说不清点下去会发生什么。

### 并发不会波及你随手点的那次确认

`ModelProbe` 原有一道单飞闸门，理由是并发招限流。最省事的改法是把它放宽到 5，但那样**所有**探测都能并发，包括你零散点的「试一下」，那时同时有几个在飞就说不清了。

实际做法是分层：整批只占一次闸门，批内按 5 路跑。于是「批跑期间零散的确认排队等着」与「批内并发是确定的 5」同时成立。

## 变化：不能用的模型名变红

| 三态 | 模型名 | 状态点 |
| --- | --- | --- |
| 能用 | 绿 | 实心绿 |
| 报错说没这个模型 | **红** | 实心红 |
| 未确认 | 常规字色 | 空心描边 |
| 正在确认 | 弱化色 | 琥珀描边并闪动 |

结论的说法收进悬停：行上不再为每个模型多占一行小字，鼠标停上去能看到这一行的判定是什么、以及它意味着什么。**「正在确认」仍留在行上**——那一态没有颜色可依，而它是「慢网关」与「点了没反应」的唯一分辨依据。

摘要行（收起时那条「模型 · 思考等级」）的不可用也从琥珀改成红，与列表里同一个颜色。同一件事换个颜色，就要学两遍。

## 变化：模型 ID 一行显示

模型 ID 不再折行，放不下时截断成省略号，完整 ID 在悬停说明的第一行。

面板够宽时不截断：四十来字符的 ID（如 `deepseek/deepseek-v4-flash-vision-preview`）约需 475px 的面板宽度。比这更窄时会截断——要让任意长度都完整显示，浮层就得无上限地跟着 ID 变宽，那会盖住整个对话区。

浮层宽度改为按内容取，以面板宽度为上限：目录里 ID 短时它就窄，ID 长时才变宽。此前是定值，两头都不理想。

## 变化：思考等级一行一档

浮层里左列模型、右列档位。档位列的宽度由它自己的内容决定，正好容下最长的档位名加一个标注，不留空白；档位名居中。

每档的用途说明收进悬停。**当前模型不支持的档位仍在行上留一个「会降级」的短标**——那不是解释，是「选了不生效」，必须先看见才能选对。

## 变化：处理中改成一圈点绕着转

对话进行中的指示器从横排三个脉冲点改成 14px 见方、8 个点的圆环，一道亮度波绕着转（周期 0.94s）。

横排三点跟在「正在读取…」这类本身就带省略号的文案旁边，两处形状重复，读起来像把省略号写了两遍。

兜底文案「正在处理…」改为「正在忙着办…」。按阶段变的那几句照旧——「正在思考…」「正在读取…」「正在写入…」全收成一句会丢掉「现在在读还是在写」，那是等待时唯一能看的东西。

## 升级说明

- 覆盖安装即可，设置、常用名单、密钥都不受影响。
- 常用名单与三态的含义没变；`v0.5.0` 标过的星、记过的判定继续有效（判定记在内存里，重启 Excel 后清空，这一点也没变）。
- 界面上的变化不需要任何配置，装完重启 Excel 即生效。

## 已知限制

- **测试整目录会真的花钱。** 每个模型一条最小请求，目录有几十个 ID 就是几十次计费请求。按钮的悬停说明会报出确切条数，点之前请先看一眼。
- **并发 5 可能撞上限流。** 被限流的模型记为「未确认」而不是「不可用」——限流说的是账号，不是模型。此时那次请求的钱花了但没换来答案，可以稍后再点一次。
- **超长模型 ID 在窄面板上仍会截断。** 完整值在悬停说明第一行。约 475px 以上的面板宽度可完整显示四十来字符的 ID。
- **判定仍是启发式的。** 判「不可用」要求服务端错误明确点名该模型；地址填错的裸 404、密钥被拒、限流、5xx、我方超时一律算「未确认」。被判不可用的模型仍然可以选中使用——判定可能已经过时。
- **判定不落盘。** 记在内存里，重启 Excel 后清空，这样网关补上配额或权限后不需要清任何缓存。
