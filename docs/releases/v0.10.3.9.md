# ChatSheet v0.10.3.9

四种接入模式在进入设置页、切换模式或 CLI 来源后自动获取状态和模型，无需先点击获取或保存。

- WorkBuddy 国内版、国际版分别复用官方登录，在当前面板内保留各自的模型选择和目录，切回后立即显示并自动核验。
- 快速切换合并同一连接的在途请求，旧模式的响应、错误和重试提示不会覆盖当前页面。
- 暂时无法连接时保留该连接的模型和目录并显示“连接待确认”；官方明确未授权时清除旧目录，显示登录入口。保存后的状态也遵循此规则。
- 自定义接口的未保存密钥草稿在刷新和模式切换时保留；仍需点击“保存设置”才更新实际对话连接。
- WorkBuddy 状态与账号按钮并排显示，组件和签到信息收为紧凑辅助行。

登录由官方组件持久保存；面板中的目录与模型选择缓存仅在本次面板会话内有效。国内版自动签到继续按原有规则运行。

安装前保存并完全退出 Excel/WPS；完成构建后运行 `powershell -File .\scripts\install.ps1 -Action install -SkipBuild`，重新打开后确认版本为 `0.10.3.9`。本版本未发布至 GitHub Release。
