# ChatSheet v0.10.3.10

修复 Codex CLI 使用 `config.toml` 自定义服务商时，因为没有 `auth.json` 而无法获取模型的问题。

- 根据 `model_provider` 读取对应服务商，支持配置中的直接 bearer token、`env_key` 环境变量和既有 API key 认证。
- 使用配置的协议与模型，Responses 不再误用 Chat Completions；保留服务商 API 根路径，不擅自添加 `/v1`。
- 配置目录支持 `CODEX_HOME`，默认仍为用户目录的 `.codex`。
- 解析错误不会显示原始配置或密钥；ChatGPT 订阅凭据不会当作普通 API key 使用。profile、额外认证命令或请求头会明确提示当前不支持。

无需修改现有 Codex 配置或创建 `auth.json`。安装前保存并完全退出 Excel/WPS，完成构建后运行 `powershell -File .\scripts\install.ps1 -Action install -SkipBuild`。本版本未发布 GitHub Release。
