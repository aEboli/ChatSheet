# ChatSheet v0.10.3.12

这是一次面向整个项目的可靠性审查版本，重点修复 WorkBuddy 账号生命周期、表格工具边界、异步取消、面板安全和本地存储的一致性问题。

## 用户可见改进

- 点击切换账号时不再把 WorkBuddy 官方桌面端或国际版客户端一起注销；登录返回后面板会重新读取登录态和模型，不再停留在旧状态。
- 登录入口只会拉起需要的窗口，重复初始化和重复探测会被合并；账号管理后的状态刷新有超时、取消和焦点冷却。
- 停止任务、关闭面板或切换工作簿后，迟到的审批、网络流和 UI 回调都会被丢弃，不会继续写入错误工作簿。
- WebView2 顶层导航仅允许 `https://chatsheet.local/...`，外部、`file:`、`data:` 和 `about:blank` 导航会被拦截。

## 表格与数据安全

- 工具范围计数改用 `long`，完整工作表尺寸不再发生整数溢出。
- 明确拒绝不连续区域，避免只按第一个 Area 执行写入、格式或清除。
- `create_table` 和 `create_chart` 增加范围上限；审批、执行、撤销和恢复绑定原工作簿。
- 设置、DPAPI 密钥和常用模型名单使用原子写入；模型名单增加跨进程互斥保护，异常中断不会清空旧文件。
- SSE 处理 BOM、没有末尾换行的事件、取消时的尾帧和网络挂起，取消请求可以及时结束。

## 安装包

Windows 预构建包包含预注册脚本、安装菜单、离线安装说明和包内 SHA-256 清单。下载 ZIP 后请先使用同目录的 `.sha256` 文件核对整体哈希，再完整解压并运行 `install.bat`。升级前保存并完全退出 Excel/WPS，安装完成后重启宿主。

完整安装步骤见 [Windows 发行包安装指南](../windows-release-install.md)。
